# Four accepted full-attention format benchmarks

[Report](results/REPORT.md) and [exact four-row results](results/RESULTS.csv) publish the completed four-dense batch: SM8, MXINT8, mixed MXINT8-Q8/MXFP4-K4, and native MXFP4 Q4/K4. Each run has 282 windows and 289,075 targets. All use decoded stored-format final Q/K operands, all legal keys, and zero TopP selection passes. This differs from the [earlier predictor-only study](../stp-format-study/scientific-synthesis-v1/REPORT.md), which recomputes selected scores with original source Q8/K8.

[Independent full acceptance](review/independent-results/full-independent-audit.json), [24-capture acceptance](review/independent-results/smoke-independent-acceptance.json), and the [delivery filename correction review](review/delivery-doc-correction/REVIEW.json) establish the completed scope. The [881-entry artifact index](results/ARTIFACT_INDEX.json) binds the original server evidence, including its original report hash. It does not bind the relocated Markdown copy: the [publication-copy manifest](../stp-format-study/scientific-synthesis-v1/PUBLICATION_COPY.manifest.json) records both hashes. Server paths and `<variant>` path templates in the report identify archived evidence, not included GitHub files.

The six SM8/MXINT8 full-format TopP jobs and ten RS jobs remain separate pending acceptance. See [publication status and design/review pointers](../stp-format-study/scientific-synthesis-v1/PUBLICATION_STATUS.md). These four results do not complete the twenty-job expansion, and historical FP/INT anchors retain their missing-gate limitation.
