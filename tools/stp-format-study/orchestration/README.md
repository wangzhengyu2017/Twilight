These tools prepare and execute the authorized format study after the parent releases the frozen code. No GPU result is claimed by their presence.

Run `orchestrate.py --study-root NEW_ROOT --matrix MATRIX --model-path MODEL --asset-dir ASSETS --controls-manifest CONTROLS` from the frozen checkout using the existing quality venv. It prints the plan. Add `--execute` only after review/release. The execution archives source, patch, environment, adopted specs, configs and assets; runs fresh six-control regression; runs every initial candidate smoke and gate; runs twelve full cells serially; writes the unified BASELINE table and fixed MX decision. An affirmative verified decision prepares a separate frozen conditional matrix and runs all six conditional smoke/full cells. The initial decision is copied to immutable INITIAL_BASELINE artifacts before conditional execution. Failures preserve logs and all completed cells. Every full command retains its gate path/hash.

The controls manifest is keyed `095`, `090`, `085`. Each entry gives absolute `int_run`, `fp_run`, `q4_run`, `q8_run` paths to compatible historical decode-on traces. These are distinct from fresh regression controls, which compare all original scoring rows and logits hashes exactly under the new source. Gate validation binds the regression report and its provenance.

The underlying runner, `python -m benchmark.attention_format.run`, also prints plans by default and requires `--execute`. Full requires `--smoke-root`. Conditional execution requires a separately activated matrix and the exact bound decision path. RS has no executable configs and remains source blocked.

`progress.py ROOT` reads each run.log until final window metrics. `index_artifacts.py ROOT --output INDEX --exclude ACTIVE_LOG` records SHA256 with absolute paths for closed files. Exclude every active parent log; final orchestration indexes its completed child logs only. Snapshot/index outputs stay under the new study root.

`python -m benchmark.attention_format.summarize --matrix MATRIX --runs-root NEW_FULL --runs-root OLD_FULL ... --output BASELINE.csv` combines full PPL/NLL, selection statistics, missing/failed states and trace pairing summaries. Include smoke roots to aggregate pair statistics. Historical sources remain read-only. Decisions require all six MXINT8 full cells and matched controls with rebound coverage, gate evidence and provenance; absent or incompatible results yield decision_unavailable.
